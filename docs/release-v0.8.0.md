HARU v0.8.0 evolves the companion surface into a quiet caring checker.

- Removes companion conversation controls such as "Let's chat" and "Another".
- HARU now offers occasional local caring check-ins such as hydration, screen breaks, food, energy, and small-win prompts.
- The user does not need to type a response. Tapping HARU's face is the acknowledgement.
- A tap produces a brief delighted/purring reaction, then HARU returns to a fresh checker state.
- Home Bubble face taps use the same acknowledgement behavior and no longer open or route into chat.
- Companion-generated chat drafts and special chat-focus routes remain removed.
- Check-ins are deliberately slower and variable (about 90–210 seconds while HARU is visible and idle) instead of the former 20-second conversation-starter loop.
- Check-ins pause while HARU is busy, in Rest mode, or while the user is typing.
- Task/reminder summaries stay privacy-preserving: counts only, not task/reminder text.
- Normal Tell HARU utility input remains available separately for tasks, reminders, commands, voice, and AI assistance.
- No new network calls, foreground services, wake locks, overlay permissions, or background polling are added.
- Map, reminders, live location, AI providers, encrypted memory, and the stable Android signing identity are unchanged.

This is a behavior-model release: HARU is now a low-friction presence that checks in with care rather than trying to start conversations.
