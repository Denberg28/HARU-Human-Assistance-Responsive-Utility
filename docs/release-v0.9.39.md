# HARU v0.9.39

Broader text-query coverage with bounded, economical AI requests.

- Routine reviews, debugging and source comparisons use direct requests; only explicit deep research starts a bounded Antigravity agent.
- Adaptive output limits and low reasoning for complex questions; ordinary Groq chat disables reasoning. Local utilities avoid redundant AI calls.
- Supplied HTTPS pages use Gemini URL context, require successful retrieval metadata, and show verified page links. Inaccessible pages give paste-text guidance without automatic retry.
- Retains explicitly listed Gemini 2.5 Flash-Lite as an economical search option. Refresh models to discover it. Access and Search entitlement depend on the Google project; 2.5 search errors do not silently switch billing tiers.
- Preserves pasted code newlines/indentation; visibly blocks input beyond 8,000 characters instead of silently truncating it.
- Exact decimal arithmetic and precise clock/date matching prevent unnecessary AI calls and incorrect local answers to flight-time questions.
- Session diagnostics show the last model and response cap. The Streamlit lab now attaches tools selectively and bounds every provider's output.

Install over HARU to preserve settings and tasks. See the query economy review for coverage, current provider economics and limitations. Live account access, actual costs and POCO acceptance still need verification; no model can guarantee answers to every question.
